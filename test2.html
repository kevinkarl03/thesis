The Drain Tokenization Problem

1. Input Log Lines
Line A: "This is a log line where version=1"
Line B: "This is a log line where logger=log_logger"
2. Tokenization (Splitting on Whitespace)
This is a log line where version=1
This is a log line where logger=log_logger
The Logic Gap:
Because Drain treats the entire Key-Value pair as a single token, it cannot differentiate between the static key and the dynamic value. Since the tokens version=1 and logger=log_logger are different, the parser assumes the entire position is variable.
