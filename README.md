## Thesis for Kevin Karlsson ens22kkn
# Umeå University

I will evaluate a bunch of state of the art log parsers in both open source datasets while also evaluating some of these logparsers on real industrial cloud native logs. The hypothesis of this thesis is that the current state of the art log parsers, while are well performing and accurate on research datasets. While when applied to industry data these parsers lack in accuracy and is not really applicable in the state that they are in.
